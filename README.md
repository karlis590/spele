# Ķer
Ķer merķis: 
Noķer pēc iespējas vairāk bandītus

Spēles noteikumi:
Vadi spēli ar bultiņu taustiņiem
Pēc katra noķertā spēles temps palielinas
Izvairies no šķēršļim
Spēle beidzās, ja spēlētājs kļūdas un ietriecas šķēršļī

## Mapju struktūra un atvēršana
- `index.html` — galvenā spēles sākumlapa
- `attēli/` — paša zīmēts PNG varonis
- `Audio/` — spēles skaņas efekts

Atvēršana: atver `index.html` interneta pārlūkā no projekta mapes.

## Dizaina izvēles un pārbaude
- Pelēks, sarkans, balts - krimināla sajūta
- Spēles laukums ir centrēts un pielāgojas arī šauram pārlūka logam.
- Pārbaudīts: attēls, skaņa un punktu skaitītājs (3 klikšķi = 3 punkti) darbojas.
- Pēc spēles pārbaudes, uzlaboju krāsu kontrastus.
